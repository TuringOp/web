# Cloudflare Tunnel Files

- `config.template.yml`: checked-in template for `cloudflared` ingress.
- `config.generated.yml`: generated by `music-jepa/scripts/run_retrain_eval_serve.py --setup-tunnel`.

Typical flow:

```zsh
cloudflared tunnel login
cloudflared tunnel create music-jepa-api
cloudflared tunnel route dns music-jepa-api music-api.turingops.ai
cloudflared tunnel --config /Users/jrule/git/music/web/cloudflared/config.generated.yml run music-jepa-api
```
